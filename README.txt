# Welcome to the Arches Project!

This is the Arches project for RCAHMWS' instance of Arches for HERs. 

To install the instance:

1. Clone the project and install Arches and Arches for HERs
2. Load the Arches for HERs package
3. Remove the installed version of the Monument resource model
4. Load the package contained within this project
5. Run the delete_concepts management command. 

Please see the [project page](http://archesproject.org/) for more information on the Arches project.

The Arches Installation Guide and Arches User Guide are available [here](http://archesproject.org/documentation/).
